# Chat Application Java:
# 💬 Java Socket Chat Application

An interactive multi-client chat system built using **Java Swing**, **Socket Programming**, and **Multithreading** for real-time communication.

---

## 🧠 Background

This project demonstrates the integration of key Java technologies to build a robust client-server architecture.

### 🎨 Java Swing – GUI Design
- Built using **Java Swing** to provide a modern, responsive, and platform-independent graphical interface.
- Supports user-friendly components: buttons, text fields, panels, scrollable message boxes.
- Event-driven architecture ensures smooth user interaction.

### 🌐 Socket Programming – Server-Client Connection
- Implements **TCP-based socket programming** to facilitate reliable and real-time communication between server and multiple clients.
- The server listens on a port and accepts incoming client connections, enabling bi-directional messaging.

### 🔄 Multithreading – Handling Concurrent Clients
- Each client is handled in a **dedicated thread**.
- Ensures the server can manage **multiple clients simultaneously** without blocking or crashing.
- Improves performance and allows real-time group messageing

---

## 🚀 Features
- 🔐 Real-time, encrypted messaging
- 👥 Multi-client support
- 💬 GUI-based chat interface
- 🧵 Efficient threading model
- ❌ Graceful client disconnect handling
